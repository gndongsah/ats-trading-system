# ATS-016 — Deterministic Backtest Harness

Status: Sprint 6 deterministic backtesting foundation.

## Goal

ATS-016 converts accepted point-in-time Layer 2 decisions into reproducible historical trade outcomes without AI, live market access or broker execution.

## Input boundary

The harness consumes:

- `HistoricalReplayContext` from ATS-012;
- actionable `SwingTriggerResult` from ATS-015;
- explicit sizing inputs;
- explicit simulation cost assumptions;
- an explicit post-entry historical exit observation.

The replay timestamp and trigger timestamp must match.

`HistoricalReplayContext` now independently rejects market observations whose event, availability or ingestion time is after the context timestamp. This closes a direct-construction bypass while preserving the ATS-012 service behavior.

## Position sizing

ATS-016 reuses `size_long_equity_position` from the accepted deterministic risk layer.

It does not implement a second sizing formula.

Current accepted risk sizing supports whole-share long equities only. Therefore the initial backtest harness fails closed for breakdown-short triggers with `UNSUPPORTED_SIDE:SHORT`. A short backtest must wait for an accepted deterministic short-sizing policy.

Sizing inputs are explicit:

- account equity;
- base risk fraction;
- available buying power;
- optional explicit regime multiplier where the accepted risk layer requires it.

## Costs

There are no hidden cost defaults.

Every run supplies a `BacktestCostModel` with:

- entry slippage in basis points;
- exit slippage in basis points;
- fee per share per side;
- fixed fee per side.

For long trades, slippage is always adverse:

- entry fill is above the trigger/reference entry;
- exit fill is below the historical exit reference.

Fees are charged exactly once on entry and once on exit.

## P&L and R

Quantity is the accepted risk-layer whole-share quantity.

Gross P&L:

`(exit fill - entry fill) * quantity`

Net realized P&L:

`gross P&L - round-trip fees`

Initial R denominator:

`(planned trigger - planned invalidation) * quantity`

The initial-risk denominator uses the written Layer 2 trigger/invalidation geometry, not the slipped fill. This keeps R anchored to the risk that was planned before execution-cost assumptions.

All finite monetary values are calculated through exact rational arithmetic and converted to finite Decimal values without depending on the ambient Decimal context.

An R multiple may be a repeating rational. ATS-016 therefore preserves:

- exact normalized numerator / denominator; and
- a deterministic 12-decimal `TradeResult.r_multiple` rendering using `ROUND_HALF_EVEN`.

## Outcome

`BacktestTradeOutcome` records:

- decision timestamp, swing setup type, regime and Setup Score for ATS-017 grouping;
- replay-context digest;
- deterministic request digest;
- sizing decision and quantity;
- planned entry/invalidation;
- cost-adjusted entry/exit fills;
- gross P&L;
- fees;
- net P&L;
- initial risk;
- exact R ratio;
- optional exact MAE/MFE ratios;
- deterministic REPLAY `TradeResult`.

Plan/result UUIDs are UUID5 values derived from the request digest. Identical inputs therefore produce identical identities and outputs.

## MAE / MFE

When the caller supplies a historical low/high range covering the entry-to-exit observation window, ATS-016 calculates price-path MAE/MFE against the actual slipped entry fill and planned initial-risk denominator.

These excursion metrics exclude transaction fees; they measure price excursion rather than accounting P&L. Their source is persisted in `TradeResult.excursion_source`.

## Safety boundary

ATS-016 does not:

- call an LLM or agent;
- fetch current/live data;
- construct broker orders;
- create live TradePlans;
- authorize Layer 3 risk;
- submit to a broker.

Every `TradeResult` generated by this harness has `run_type=REPLAY`, preserving ATS-028 result isolation.
